## 권장 순서

01 → 03 → 04 → 05 → 06 → 07 → 08

- 앞 문서의 ID를 뒤 문서가 인용하므로 순서대로 만드는 것을 권장한다.
- 02 R&D 사업 문서는 R&D 지원사업을 준비할 때만 만든다. 01 이후 어느 시점에든 작성할 수 있다.

## 사용 방법

1. 템플릿을 열어 `{{ }}` 자리표시자(제품명, 고객사, 참고 자료 경로 등)를 실제 값으로 바꾼다.
2. 앱 안에서는 "운영 탭에 붙여넣을 지시문"을 운영 탭에 붙여넣는다. 운영자 에이전트가 계획·배정하고, 결과는 Codex 리뷰와 Claude 재검토를 거친다.
3. 앱 밖에서는 "Claude에 바로 붙여넣는 전체 프롬프트"를 Claude에 붙여넣는다.
4. 결과 문서를 "검토 기준" 체크리스트로 확인하고, "사용자 결정 필요 항목"과 "확인 필요 항목"을 직접 정리한다.

## 공통 원칙

- 모든 사실 주장에는 출처(파일경로:줄번호)를 달고, 근거가 없으면 "확인 필요"로 표시한다.
- 수치·고객사명·성과를 지어내지 않는다. 측정하지 않은 성과를 결과로 쓰지 않는다.
- 작성자 제안과 사용자 결정을 구분한다. 문서 작성 완료는 사용자 검토·합의 완료가 아니다.
- 에이전트는 허용된 프로젝트 경로 안에서만 쓰고, 산출물은 기본적으로 `crewgenai-output/` 아래에 둔다.
- 고객 원문, 개인정보, 비밀값은 문서에 옮기지 않는다.
