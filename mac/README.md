# CREWGENAI 개발팀 관리 — 설치·사용 설명서

CREWGENAI 개발팀 관리(앱 이름 `CREWGENAI Agent Workspace`)는 사용자가 팀장이 되어 AI 직원(Agent) 팀을 구성하고, 지시를 내려 작업을 맡기는 macOS 데스크톱 앱이다. 앱에는 AI 모델이 들어 있지 않다. 각 Mac에 설치되어 로그인된 **Claude CLI**(작업)와 **Codex CLI**(교차 검토)를 실행한다.

- 버전: 검토본 `0.0.0-review.20261110`
- 지원 환경: macOS, Apple Silicon(M1 이상). Intel Mac용 빌드는 아직 없다.
- 화면별 자세한 사용법: [resources/docs/GUIDE.md](resources/docs/GUIDE.md). 앱 안의 **사용법(?)** 에서도 같은 내용을 볼 수 있다.

## 1. 설치 — 다른 Mac에서 Git으로 받아 빌드하기

설치 파일(.dmg)은 Git에 포함하지 않는다(`release/`는 `.gitignore` 대상). 각 Mac에서 소스를 받아 한 번 빌드한다.

### 준비물

| 항목 | 용도 | 확인 방법 |
|---|---|---|
| Git | 소스 받기 | `git --version` |
| Node.js(npm 포함) | 앱 빌드. 이 앱은 v26에서 빌드·검증했다 | `node -v` |
| Claude CLI | AI 직원 실행(필수) | `claude --version` |
| Codex CLI | 교차 검토(선택) | `codex --version` |

### 순서

1. 저장소를 받는다. 이미 받아 두었으면 `git pull`만 한다.

   ```bash
   git clone https://github.com/heum/crewgenai-agent-workspace.git
   ```

2. `mac` 폴더에서 의존성을 설치하고 설치 파일을 만든다. 몇 분 걸린다.

   ```bash
   cd crewgenai-agent-workspace/mac && npm ci && npm run dist
   ```

3. `release/` 폴더에 생긴 `CREWGENAI-Agent-Workspace-…-arm64.dmg`를 열고, 앱을 **응용 프로그램** 폴더로 끌어 놓는다.

4. 응용 프로그램 폴더에서 앱을 연다.

### 처음 열 때 "확인되지 않은 개발자"로 막히는 경우

이 앱은 Apple 정식 서명이 없다(임시 서명). 그 Mac에서 직접 빌드한 앱은 보통 그대로 열리지만, 다른 Mac에서 만든 .dmg를 AirDrop·메신저·드라이브로 옮겨 오면 막힐 수 있다. 다음 중 하나로 연다.

- 앱을 한 번 열어 본 뒤 **시스템 설정 → 개인정보 보호 및 보안**에서 **그래도 열기**를 누른다.
- 터미널에서 다운로드 표시를 지운다.

  ```bash
  xattr -dr com.apple.quarantine "/Applications/CREWGENAI Agent Workspace.app"
  ```

### 빌드 없이 바로 띄워 보기(개발용)

설치하지 않고 확인만 할 때는 앱 폴더에서 다음을 실행한다. 창을 닫으면 끝나며, 계속 쓸 때는 위의 .dmg 설치를 권한다.

```bash
npm ci && npm start
```

## 2. 처음 설정

1. **CLI 로그인** — 터미널에서 한 번씩 로그인한다. 앱은 계정 정보와 토큰을 저장하지 않는다.

   ```bash
   claude auth login
   ```

   ```bash
   codex login
   ```

2. **준비 상태 확인** — 앱 왼쪽 아래의 **Claude CLI**·**Codex 리뷰** 표시가 초록이면 실행할 수 있다. 빨간색이면 표시를 눌러 안내를 따른다.
3. **실행 엔진 확인** — **설정(⚙)** 에서 실행 엔진이 **실제 Claude CLI**인지 확인한다. 모의 실행은 시험용이다.

## 3. 기본 사용 흐름

| 단계 | 탭 | 하는 일 |
|---|---|---|
| 1 | 기획 | **+ 새 프로젝트** → 이름·목표·작업할 로컬 폴더·자동 수정 허용 경로를 정하고 저장한다. 폴더는 저장소 하나 또는 여러 저장소를 담은 상위 폴더(예: `~/Documents/GitHub`)를 고른다. 상위 폴더면 허용 경로를 `jodalCrew/src`처럼 저장소 이름부터 적는다. |
| 2 | 기획 | **완성 문서 목록…** 에서 프로젝트에 필요한 문서(표준 세트를 프로젝트에 맞게 조정)를 확인한다. 문서마다 **프롬프트 복사** → 자신의 Claude·GPT 환경에서 문서를 만든다 → **파일 올리기**로 프로젝트 폴더에 넣는다 → 내용을 확인하고 **검토 완료**를 누른다. |
| 3 | 직원 | AI 직원을 구성한다. 역할, 사용할 도구, 허용 명령을 정한다. |
| 4 | 운영 | 아래 고정 입력창에 지시를 쓰고 **지시하기**를 누른다. 오퍼레이터가 계획 → 직원 배정 → 검사·검토 → 결과 통합을 반복한다. |
| 5 | 운영 | 진행 중에는 **추가 지시**·**지금 반영**·**중단**을 쓸 수 있다. 질문이나 근거 문서 보완 요청이 오면 답하거나 문서를 보완하고 계속한다. 완료 보고를 확인하고 **여기서 종료** 또는 **추가 지시하고 계속**을 고른다. |
| 6 | 실행 | 단계별 상세 기록, 결과물 파일 열기, 직접 짠 흐름 실행, 팀장 검토를 한다(선택). |

- 근거 문서가 비어 있거나 모호하면 오퍼레이터는 작업을 배정하지 않고, 문서별로 채울 내용을 보여 준 뒤 미션을 멈춘다. 문서를 보완한 다음 **보완했으니 다시 확인**을 누른다.
- Claude 플랜 사용 한도에 닿으면 미션은 멈추고, 한도가 풀리는 시각에 자동으로 이어 간다. **지금 다시 시도**로 앞당길 수 있다.

자세한 화면 설명은 [GUIDE.md](resources/docs/GUIDE.md)를 본다.

### 연결 폴더와 git

- 연결 폴더는 git 저장소이거나, **바로 아래에 git 저장소 폴더가 있는 상위 폴더**여야 직원별 커밋·스냅샷·되돌리기를 쓸 수 있다.
- 여러 저장소를 담은 상위 폴더에는 `git init`을 하지 않는다. 저장소 안에 저장소가 생겨 기록이 꼬인다.
- 저장소가 아닌 기존 작업 폴더 하나를 연결할 때만 그 폴더에서 `git init` 후 첫 커밋을 만든다. `git init`은 `.git` 폴더만 만들고 기존 파일을 바꾸지 않는다. 첫 커밋 전에 비밀값·큰 폴더를 `.gitignore`에 넣는다.
- git을 쓰지 않으려면 **설정 → 직원별 git 커밋·미션 스냅샷 사용**을 끈다. 이 경우 되돌리기를 쓸 수 없다.

## 4. 최신 버전으로 업데이트

```bash
git pull && cd mac && npm ci && npm run dist
```

새로 생긴 .dmg로 응용 프로그램 폴더의 앱을 덮어 설치한다. 기존 기록(아래 데이터)은 유지된다.

## 5. 데이터와 Mac 간 이동

| 대상 | 위치 | 다른 Mac으로 |
|---|---|---|
| 앱 기록(프로젝트·직원·미션·문서 목록) | `~/Library/Application Support/CREWGENAI 개발팀 관리/workspace.db`(메뉴 **파일 → 데이터 폴더 Finder에서 보기**) | 따라가지 않는다. 새 Mac은 빈 상태로 시작한다. |
| 완성 문서·결과물 | 각 프로젝트 폴더(문서 경로, 산출물 위치) | 프로젝트 저장소에 커밋하면 따라간다. |
| Claude·Codex 로그인 | 각 CLI가 관리 | Mac마다 따로 로그인한다. |

앱 기록 폴더를 복사해 옮기는 방법은 검증하지 않았다. 기록 안의 프로젝트 폴더 경로가 원래 Mac 기준이라 맞지 않을 수 있다.

## 6. 문제 해결

| 증상 | 확인할 것 |
|---|---|
| `npm ci` 실패 | `node -v`로 Node.js 설치를 확인한다. `node_modules`를 지우고 다시 실행한다. |
| 앱이 열리지 않음(개발자 확인) | 위 "처음 열 때" 항목을 따른다. |
| Claude CLI 빨간색 | 터미널에서 `claude --version`, `claude auth login`. 앱을 다시 연다. |
| Codex 리뷰 빨간색 | `codex login`. Codex가 없어도 Claude 작업은 할 수 있으나 교차 검토는 실행되지 않는다. |
| 미션이 "사용 한도 대기" | 표시된 시각까지 기다리거나 **지금 다시 시도**를 누른다. |
| Intel Mac | 현재 빌드 설정은 Apple Silicon 전용이다. |

## 7. 알려진 제한

- 이 폴더는 macOS Apple Silicon판이다. Windows판은 저장소의 [`windows/`](../windows/) 폴더에 있다. Intel Mac은 아직 지원하지 않는다.
- Apple 정식 서명·공증이 없다. 다른 Mac으로 옮긴 설치 파일은 처음 열 때 확인 절차가 필요하다.
- 다른 Mac에서 처음부터 받아 빌드하는 과정은 아직 직접 검증하지 않았다(작성 Mac에서 같은 명령으로 빌드·설치 시험만 함).
- 근거 문서 보완 요청, 사용 한도 자동 재개, 작업 중 직원 표시는 모의 실행으로 흐름만 검증했다. 실제 Claude에서의 판단 품질은 사용하며 확인이 필요하다.

## 공개 범위

이 저장소는 앱 소스·검사·사용법을 분리한 검토본입니다. 내부 프로젝트 기록과 실행 DB·인증 자료·설치 파일은 포함하지 않습니다. 라이선스는 아직 지정하지 않았습니다.
